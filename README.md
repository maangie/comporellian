# Comporellian

『ファウンデーションと地球』でゴラン・トレヴィズが観測した惑星コンポレロン（Comporellon）を、Three.js による実際の3D照明で再現したブラウザ用ビジュアライゼーション。

## フォルダ構成

```
comporellian/
├── README.md          このファイル
└── comporellon.html   コンポレロン惑星の3D可視化（単体HTML）
```

## comporellon.html について

`comporellon.html` をブラウザで直接開くだけで動作する単体HTMLファイル。Three.js (r128) をCDN (`cdnjs.cloudflare.com`) から読み込むため、閲覧にはインターネット接続が必要。

### 再現している設定

- 地軸傾斜 21°、太陽赤緯 15°（南半球の盛夏寄り）
- 南極側から観測（自転は時計回り）
- やや低温の橙色恒星
- 氷冠の大きい寒冷な世界

光源を1つに絞ることで、明暗境界線（ターミネーター）が物理的に正しい位置に自動計算される点がポイント。「極から明暗境界線までの角距離 = 太陽赤緯 = 季節」という関係を、スライダーを動かして視覚的に確認できる。

これを示すために、観測している極（南極点）から最寄りの明暗境界線上の点まで、球面に沿って赤い円弧（季節を示す弧）を描画している。弧の角度は常に太陽赤緯と一致するように計算され、中点には角度のラベル（例: `15°`）が表示される。スライダーで赤緯を変えると弧の長さも連動して変わり、両者が一致し続けることを確認できる。

### 操作方法

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 視点を回転 |
| ホイール | ズームイン・アウト |
| 太陽赤緯スライダー | 季節（太陽赤緯 0〜21°）を変更 |
| 自転を止める | 惑星の自転アニメーションを一時停止 |
| 視点リセット | カメラを初期位置に戻す |

### 技術メモ

- 惑星表面・雲のテクスチャは `<canvas>` 上で手続き的に生成（外部画像ファイル不使用）
- 乱数は `mulberry32` による決定論的な疑似乱数生成器を使用し、毎回同じ地形パターンを再現
- 明暗境界線・副太陽点・自転軸・両極マーカー・季節を示す弧はワールド座標に固定されたジオメトリとして描画し、惑星本体の自転（`planetPivot`）とは独立させている
